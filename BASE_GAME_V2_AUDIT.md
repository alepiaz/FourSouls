- **Required architecture (proposal):** keep Game as trusted referee; expose immutable detached per-viewer observations (public board including hand/deck counts, public discard/stack/state; own hand; explicitly authorized private inspection results; no raw Game/Effect/RNG objects, secret card IDs or nested mutable references). Separate viewer, active player, priority holder and decision chooser. Project legal actions and private decisions only to their owner; submit opaque action/decision tokens to authoritative validation. Separate public and per-viewer event projections from internal logs. Continuous private information permission is a read-only projection of current top card, independent of stack activation/priority, refreshed on deck changes and revoked on turn/source changes. A one-shot look produces a private snapshot, not permanent access to later top cards. Public reveal is a separate audience. Preserve legitimately learned information without leaking new hidden state. Trusted debug/replay remains explicitly privileged. For untrusted Python agents a DTO alone is not a sandbox: isolate process/service as needed.
- **Acceptance criteria:** two-player off-turn CLI hand and quota; own hand/other hand count; no raw opponent hand/deck identity in observation/actions/events/serialization (including nested references and stable IDs); distinct observations for states differing only in secrets are identical to unauthorized viewer, with same authorized public data; raw draw event retained internally but opponent gets count only; public reveal vs private look; authorized temporary/continuous views (There's Options own turn incl. off-priority, current top changes, loss/transfer, end turn, empty deck); chooser-only private hand candidates for Incubus/Dead Bird/Tarot Cloth; wrong actor/stale decision rejected; no mutation of engine via observation; no RNG seed/state exposure to competitive agent; correct off-turn priority and no auto-pass of meaningful responses. Keep these tests separate from trusted deterministic bot acceptance tests.
- **Roadmap association:** Sprint 20 private deck inspection, Sprint 21 hand transfer, Sprint 23 decision/trigger presentation, Sprint 25 static permissions, Sprint 17 priority/quiescence, Sprint 18 simulation runner. The cross-cutting observation boundary and privacy regressions are not explicitly assigned as a complete deliverable in the pinned roadmap; recommend foundation before fair agent comparisons (Sprint 19) and before private inspection mechanics.
